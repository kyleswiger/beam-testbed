# beam-testbed

Phoenix 1.8 LiveView test app that exists to prove the Elixir/BEAM path
through the shared tooling: `elixir-ci.yml` gates, `oci-build-push.yml` to
ECR, `ecs-deploy.yml` to a Fargate service built by the
`ecs-fargate-service` Terraform module. Framework conventions are in
`AGENTS.md` (generated by Phoenix).

- No database. Adding Ecto means adding RDS/Aurora and a `pre-deploy-command`
  migration task; keep that a separate, deliberate change.
- Terraform is applied by hand from `terraform/` (state in the shared account
  bucket, key `beam-testbed/terraform.tfstate`). CI only plans.
- `SECRET_KEY_BASE` lives in SSM `/beam-testbed/secret_key_base` (SecureString),
  referenced by ARN in Terraform, never by value.
- Deploys roll forward from `main`; rollback is `aws ecs update-service
  --task-definition <previous>` (printed in every Deploy run summary).
